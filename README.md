## Open-Source Generators

- [Changesets](https://github.com/changesets/changesets) - Changesets is a tool for managing versioning and changelogs in multi-package JavaScript repositories. It uses markdown files to describe changes and generates changelogs automatically. The project is open source. ([Read more](/details/changesets.md)) `Open Source` `JavaScript` `Monorepo` `CLI`
- [conventional-changelog](https://github.com/conventional-changelog/conventional-changelog) - conventional-changelog is a set of tools for generating changelogs from conventional commit messages. It includes CLI and programmatic APIs for Node.js projects. The project is open source. ([Read more](/details/conventional-changelog.md)) `Open Source` `Node.js` `CLI` `Conventional Commits`
- [git-cliff](https://github.com/orhun/git-cliff) - git-cliff is a highly customizable changelog generator that follows conventional commit specifications. It generates changelog files from Git history and supports custom commit parsers. The project is open source and self-hosted. ([Read more](/details/git-cliff.md)) `Open Source` `Self-Hosted` `CLI` `Git`

## Release Automation

- [release-it](https://github.com/release-it/release-it) - release-it is a CLI tool for automating Git releases and changelog generation. It supports bumping versions, creating Git tags, and publishing to package registries. The project is open source. ([Read more](/details/release-it.md)) `Open Source` `CLI` `Git` `Automation`
- [release-please](https://github.com/googleapis/release-please) - release-please automates release pull requests and changelog generation using conventional commits. It is maintained by Google and supports monorepos and multiple package managers. The project is open source. ([Read more](/details/release-please.md)) `Open Source` `Automation` `Google` `Monorepo`
- [semantic-release](https://github.com/semantic-release/semantic-release) - semantic-release automates version management and package publishing based on conventional commits. It generates changelogs and triggers CI/CD releases for Node.js projects. The project is open source. ([Read more](/details/semantic-release.md)) `Open Source` `Automation` `Node.js` `CI/CD`
- [standard-version](https://github.com/conventional-changelog/standard-version) - standard-version automates versioning and CHANGELOG generation using conventional commits. It is designed for JavaScript projects and integrates with Git workflows. The project is open source. ([Read more](/details/standard-version.md)) `Open Source` `JavaScript` `Git` `Automation`
